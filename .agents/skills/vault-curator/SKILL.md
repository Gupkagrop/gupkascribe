# Регламент куратора базы знаний (Vault Curator)

## 🎯 Правила архитектурной целостности

1. **Универсальная поддержка дисциплин (Dynamic Subject Discovery):**
   - Куратор динамически сканирует все папки предметов в корне Obsidian Vault (по умолчанию: `Математика Матанализ`, `Дискретная математика`, `Анализ данных и ИИ`, `Алгебра, геометрия и теория дифференциальных уравнений`, а также любые вновь созданные дисциплины).
   - Заметки, учебники и термины должны принадлежать активным курсам.
   - Любые ссылки `[[...]]` на удалённые или исключённые предметы (например, ОРГ, ИнЯз, ПРОГ, ИТиС, ОПД) недопустимы и подлежат очистке.

2. **Zero Broken Links Protocol:**
   - Каждая wiki-ссылка вида `[[Имя заметки]]`, `[[Имя|Псевдоним]]` или `[[Имя#Раздел]]` обязана указывать на реально существующий на диске Markdown-файл в Vault.

3. **Абсолютная изоляция `Дедлайны и ДЗ.md`:**
   - Запрещены любые ссылки вида `[[Дедлайны и ДЗ]]` из заметок пар, терминов или учебников.
   - В самом файле `Дедлайны и ДЗ.md` запрещены прямые ссылки `[[...]]` на пары (только обычный текст вида `Источник: МатАн - Практика 11...`).
   - Это гарантирует чистоту Obsidian Graph View без междисциплинарного склеивания через дедлайны.

## 🛠️ Порядок проведения аудита

1. **Автоматический аудит ссылок:**
   Запустить проверку через Python:
   ```powershell
   uv run python -c "
   from src.vault_utils import verify_link_integrity, get_vault_stats
   import os

   vault = os.path.expanduser('~/Documents/Obsidian Vault')
   res = verify_link_integrity(vault)
   print('Битых ссылок:', len(res['broken_links']))
   print('Сторонних ссылок:', len(res['untracked_subject_links']))
   if res['broken_links']:
       for b in res['broken_links']:
           print('  ❌', b)
   "
   ```

2. **Устранение обнаруженных дефектов:**
   - Если ссылка ведёт на отсутствующий термин — создать атомарную карточку в папке `Термины/` соответствующей дисциплины.
   - Если обнаружена устаревшая ссылка без префикса (например `[[Лекция 1]]` вместо `[[МатАн - Лекция 1...]]`) — актуализировать ссылку.
   - Если обнаружены ссылки на удалённые дисциплины — удалить упоминание или очистить контекст.

3. **Синхронизация Canvas:**
   - Убедиться, что свойства `file` в узлах файлов `.canvas` соответствуют реальным путям на диске.
